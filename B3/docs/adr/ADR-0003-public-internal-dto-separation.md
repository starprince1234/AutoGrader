# ADR 0003 公开 / 内部 DTO 分离与受保护字段永不外泄

- **状态**：接受（2026-09-15；模块级冻结见 `ADR-0004`）
- **背景**：
  - `RQ-B-3-10` 验收 2：公开 DTO（`GET /api/v1/questions`、题目详情）中不存在 `reference_answer`、`hidden_cases`、`expected_output` 等字段。
  - 参考答案 / 隐藏用例 / expected output 一旦进入公开响应，即构成学术诚信事故（`MAIN/docs/workstreams/B3.md` §5 WP-B3-A 风险："公开 DTO 泄漏是最高危缺陷"）。
  - 靠代码审阅防泄漏不可靠，必须靠**物理分离 + 自动化契约测试**。
- **决策**：
  - 公开 DTO 与内部 DTO **物理分离**：不同模块 / 不同文件，禁止复用同一模型类；公开 DTO 的字段集合不含任何受保护字段。
  - 受保护字段只存在于内部 DTO（`evaluation-package`、受保护存储读模型），且只服务间可读（`evaluation-package` 接口需服务间认证）。
  - 自动化契约测试（TC-QST-01）**逐字段断言公开响应字段缺失**，而非断言值为空。
  - 受保护内容独立权限（数据库层或对象层），普通查询不可读（TC-QST-03 / 3-10-3）。
- **后果**：
  - 获得：泄漏由测试机械拦截，不依赖评审自觉；学术诚信边界可验证。
  - 获得：公开/内部模型解耦，公开契约演进不牵连内部结构。
  - 付出：需维护两套 DTO 与映射；新增字段时必须回答"属于公开还是内部"。
  - 遗留风险：若内部 DTO 被误注入公开路由，或序列化器默认导出全部字段，仍可能泄漏；需在序列化层做白名单 + 契约测试双保险。
