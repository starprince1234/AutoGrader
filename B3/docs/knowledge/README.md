# B3 知识笔记（Knowledge）

记录**重复出现且根因已验证**的问题与稳定修复；一次性问题不收录（避免噪音）。

## 收录标准

1. 同一根因在 B3 中出现**至少两次**，或影响面跨模块。
2. 已有**稳定修复**并被真实验证。
3. 只记录事实与处置，不写教程、不写过程流水账。

## 命名规则

`YYYY-MM-DD-<short-problem>.md`（如 `2026-09-16-uv-cache-write-failure.md`）。

## 笔记模板

```md
# <简短问题名>

- 现象：
- 重复触发条件：
- 根因：
- 最终修复：
- 预防措施：
- 关联证据（日志/命令/阶段文档路径）：
```
