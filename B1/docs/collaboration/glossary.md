# B1 术语表

本模块专有术语；跨模块术语与标识见 `../../../MAIN/docs/api/identifiers.md`，需求术语见 `../../../MAIN/docs/requirements/rq-catalog.md`。

| 术语 | 含义 |
|---|---|
| 泳道（swimlane） | B1 内三条并行工作包（WP-B1-A/B/C）的划分 |
| 草稿 | 学生未提交的编辑器内容，仅存浏览器本地，不等于"已提交" |
| 列映射（column mapping） | 名单导入时把上传文件的列名对应到期望字段的人工步骤 |
| 被拒行 | 名单导入逐行校验中被拒绝（重复学号/缺失必填等）的数据行，必须出现在结果报告 |
| 角色可见性守卫 | 按当前角色控制页面/入口**可见性**的前端路由逻辑；**不构成安全边界** |
| SSE（Server-Sent Events） | B2 向 B1 推送评测实时进度的通道（`GET .../events`） |
| 契约测试夹具 | 用冻结契约生成的固定响应样本，驱动组件/单元测试（非 mock 成功交付） |
| 下钻（drill-down） | 从成绩列表进入单次评测逐项证据（规则/用例→得分/失分）的交互 |
| 终态 | 评测的结束状态：`completed` / `rejected` / `failed` |
