# ADR 0001 B1 无权威数据与草稿边界

- 状态：接受
- 背景：
  - B1 是静态 Web 客户端，`module.yaml` 声明 `database.schema: none`。
  - 课程需求要求名单导入/编辑、成绩查询/导出、提交等交互，但这些数据的权威在 B4/B3/B2。
  - 若 B1 在浏览器本地持久化权威数据（名单、成绩、题目版本、评测报告），会出现多端不一致、过期数据、越权数据残留、敏感信息（参考答案/隐藏用例/PII）泄漏等风险。
- 决策：
  1. B1 **不拥有**任何权威数据；一切权威数据即时从 B4/B3/B2 接口获取，界面只做展示与交互。
  2. 浏览器本地存储**仅允许**：未提交草稿（编辑器内容 + 题目上下文）与 UI 偏好。
  3. 明确**禁止**在浏览器本地存储：访问/刷新令牌、cookie 值、参考答案、隐藏用例、学号明文之外的 PII、任何权威业务数据。
  4. 草稿"未提交"语义与"已提交"严格区分：提交成功即清除本地草稿，断网只恢复草稿，不视为已提交（RQ-B-1-50-4）。
- 后果：
  - 获得：无权威数据漂移、无本地越权数据残留、无参考答案泄漏面；刷新页面即可拿最新数据。
  - 获得：与 `RQ-B-1-20`（前端隐藏不是安全边界）、`RQ-B-1-99`（日志不含敏感内容）的约束一致。
  - 付出：离线能力弱——断网时只能编辑草稿，不能看最新权威数据。
  - 遗留风险：草稿若包含学生自写答案代码，仍属"仅本地"内容，必须确保其不进入前端日志与任何统计上报。
