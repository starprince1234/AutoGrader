# B1 范围与非目标

## 范围：本模块交付什么

B1 交付学生 / 教师 / 管理员三类角色的 **Web 用户界面**（静态 React 客户端），覆盖 7 条需求：

| RQ | 交付物（交互层） |
|---|---|
| `RQ-B-1-10` | 名单导入向导：上传 PDF/XLSX → 解析预览 → 列映射 → 逐行校验 → 人工确认 |
| `RQ-B-1-20` | 名单/选课编辑表格 + 并发冲突提示 + 角色可见性路由守卫 |
| `RQ-B-1-30` | 成绩总表（课程+课序筛选、汇总统计）+ 单次评测逐项证据下钻 |
| `RQ-B-1-40` | 富文本题干渲染（安全子集）+ 图片加载 + 题目版本切换 |
| `RQ-B-1-50` | Monaco 代码编辑器 + 提交表单与校验 + SSE 实时进度 + 草稿本地保存 |
| `RQ-B-1-60` | 成绩导出对话框（XLSX/CSV）+ 下载 |
| `RQ-B-1-99` | 前端结构化日志（非敏感事件 + 接口错误 + 渲染异常，可选上报） |

B1 的所有"数据"都来自对 B4/B3/B2 接口的调用；B1 本身不产生权威数据。

## 非目标（最重要，防越界）

- **不解析、不落库名单**：PDF/XLSX 的解析与数据库写入由 B4 承担；B1 只负责上传、列映射、预览与确认交互。
- **不拥有权威数据**：学生、课程、课序、选课、成绩、题目、评测全部归 B4/B3/B2。
- **不做安全边界**：前端隐藏按钮/路由守卫只是体验优化；权限判定在服务端（B4/B2/B3）执行。
- **不直接访问基础设施**：不连 PostgreSQL、不连 NATS、不导入任何后端代码/ORM。
- **不做评测/评分逻辑**：不计算分数、不生成报告（那是 B2）。
- **不实现服务端路由**：`module.yaml` 的 `routes: []`，B1 不注册任何服务端端点。
- **不在浏览器持久化权威数据**：见 `../database/schema.md`。

## 角色与用例

| 角色 | 主要用例 |
|---|---|
| 学生 | 浏览题目与提交作业、查看本人成绩、查看评测实时进度与逐项证据 |
| 教师 | 导入/编辑名单、发布课程/课序下的作业、查看班级成绩、导出成绩 |
| 助教 | 在授权课程作用域内编辑名单/选课（与教师同 UI，作用域更小） |
| 管理员 | 通过 B4 接口完成用户与角色管理（B1 呈现，不要求新增专属页面） |

## 上游输入 / 下游输出去向

- **上游输入**：B4（身份会话、课程/课序/选课、名单导入任务）、B3（已发布题目与版本、题干资源）、B2（提交受理、评测运行与 SSE、成绩与报告、导出文件）。
- **下游输出去向**：用户浏览器（页面渲染）；向 B2 发出的提交请求、向 B4 发出的名单确认、向 B2 发出的导出请求；可选的前端日志上报（无明确下游时本地丢弃）。
