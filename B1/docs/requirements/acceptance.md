# B1 验收标准（可执行）

逐条 RQ 的实现级验收，比 `../../../MAIN/docs/requirements/rq-catalog.md` 更贴近 B1 交互实现。每条采用 Given/When/Then 风格，**必须可执行**；"可观测结果"指操作者能在页面或网络面板看到的现象，或对后端接口断言的结果。

前置通用条件：已以合法身份登录；`VITE_API_BASE_URL=/api`；后端为契约测试夹具或真实 B4/B3/B2（接口冻结后）。

## RQ-B-1-10 名单导入

1. 导入 PDF 与 XLSX 各渲染逐行预览与错误行标注
   - Given 教师已登录；When 依次上传一份合法 PDF 与一份合法 XLSX 名单；Then 两个文件都进入"解析预览"，逐行显示姓名/学号/课程编号/课序号，错误行被标注。
2. 列名不匹配进入列映射且不自动猜测
   - Given 上传名单的列名与期望列不一致；When 解析结果不确定；Then 界面进入"列映射"步骤，不自动猜测；无法唯一映射时明确报错并允许人工指派。
3. 重复学号/缺失必填逐行标红并给原因；被拒行出现在结果报告
   - Given 名单含重复学号或缺失必填字段；When 预览；Then 相应行标红并给出原因；确认后被拒绝的行出现在结果报告中，不静默丢弃。
4. 确认前零写入；确认可重放且幂等
   - Given 已进入预览但未确认；When 观察后端（B4）；Then 名单无任何写入；确认操作重复触发返回同一结果，不产生重复数据。
5. 预览不渲染学号以外的敏感信息
   - Given 名单含邮箱/身份证等；When 预览；Then 页面不渲染学号以外的敏感信息（如邮箱全量、身份证号）。

## RQ-B-1-20 名单编辑 + 权限

1. 学生不可见且直接调用编辑接口 403
   - Given 学生登录；When 打开名单相关页面；Then 编辑入口不可见；学生若直接调用编辑接口得到 403（证明后端独立校验）。
2. 助教/教师仅可编辑授权课程作用域；跨课程 403 且留审计
   - Given 教师仅授权课程 A；When 尝试编辑课程 B 名单；Then 返回 403 且 B4 审计表产生记录。
3. 每次成功编辑留审计
   - Given 教师成功编辑某行；When 查询 B4 审计；Then 记录含操作者、目标、变更前后值摘要、时间、请求 ID。
4. 并发冲突提示，不静默覆盖
   - Given 两个教师基于同一 `updated_at` 编辑同一行；When 后提交者保存；Then 得到冲突提示，不静默覆盖他人修改。

## RQ-B-1-30 成绩查询

1. 教师按课程+课序筛选看到全班与汇总统计
   - Given 教师登录；When 选择课程+课序；Then 看到全班成绩列表及汇总（提交数、平均分、通过率）。
2. 学生仅见本人，改参数越权 403
   - Given 学生登录；When 查询成绩并尝试改 `student_id` 参数；Then 越权请求 403。
3. 每行可下钻逐项证据
   - Given 某次评测已完成；When 点击成绩行；Then 下钻到逐项证据（规则/用例 → 得分/失分原因）。
4. 未完成评测显示状态不显示 0 分
   - Given 存在 queued/running/failed 的评测；When 查看成绩列表；Then 显示对应状态，不以 0 分伪装成已完成。
5. 同名同姓以学号区分
   - Given 存在同名同姓学生；When 查看成绩；Then 以学号区分显示，不合并记录。

## RQ-B-1-40 题目展示

1. 加粗/列表/行内代码/代码块/表格/图片正确渲染
   - Given 题目含上述元素；When 打开题目详情；Then 全部正确渲染。
2. 图片受控 URL，未授权 403，响应不伪装 text/html
   - Given 未授权用户；When 请求题目图片；Then 403，且响应头不执行脚本（无 text/html 伪装）。
3. 富文本不执行脚本/内联事件（XSS 被拦截）
   - Given 题干含脚本/内联事件；When 渲染；Then 不执行，XSS 用例被拦截。
4. 公开 DTO 无参考答案/隐藏用例/expected output
   - Given 获取题目详情（契约层与 UI 层双重校验）；Then 响应与渲染均不出现参考答案、隐藏测试用例、expected output。
5. 版本切换不改变已发布版本渲染
   - Given 存在多个已发布版本；When 切换查看历史版本；Then 各版本渲染内容稳定，不因切换而改变。

## RQ-B-1-50 提交

1. 携带 question_version_id/course_id/section_id/idempotency_key；重复提交返回同一 submission_id
   - Given 学生提交；When 同一幂等键重复提交；Then 返回同一 submission_id，不产生重复评测。
2. 超限前端拦截 + 后端 422
   - Given 提交超过题目声明大小/文件数上限；When 提交；Then 前端提交前拦截并明确提示；直接调用后端同样 422 拒绝。
3. 状态机 received → validated → queued → running → completed|rejected|failed，前端与后端一致
   - Given 提交后；When 观察状态迁移；Then 前端进度与后端状态一致。
4. 断网后重开页面可恢复未提交草稿，草稿≠已提交
   - Given 编辑中网络中断；When 重新打开页面；Then 恢复本地草稿，草稿不被视为已提交。
5. 断线重连 SSE 不重复展示历史进度
   - Given SSE 连接中断后重连；When 继续接收进度；Then 按 event_id/序号去重，不重复展示历史进度。
6. 提交他人课程/题目 403
   - Given 学生提交不属于自己的课程/题目；When 提交；Then 403。

## RQ-B-1-60 成绩导出

1. 导出文件包含学号/姓名/课程编号/课序号/题目/得分/满分/提交时间/评测 ID
   - Given 教师按筛选导出；When 下载并打开；Then 上述列齐全。
2. 公式注入字符被转义
   - Given 成绩单元格值以 `=` `+` `-` `@` 制表符 回车 开头；When 导出；Then 被转义，有对应测试用例。
3. 导出与页面查询口径一致
   - Given 同一筛选条件；When 对比导出文件与页面查询结果；Then 完全一致。
4. 学生调用导出 403
   - Given 学生登录；When 调用导出接口；Then 403。
5. 中文不乱码
   - Given 导出含中文；When 下载；Then 文件名与响应头含 UTF-8 声明，中文不乱码。

## RQ-B-1-99 运行日志

1. 成功提交/导出/导入各产生一条结构化日志
   - Given 执行任一成功操作；When 检查前端日志；Then 产生一条 JSON 行，含 timestamp/level/event/request_id。
2. 未捕获异常上报含 request_id
   - Given 发生未捕获异常；When 上报；Then 含 request_id，可与后端日志关联。
3. 生产构建无调试级日志与源码；日志不含 token/答案
   - Given 生产构建；When 检查日志输出；Then 无调试级日志与源码内容，无 token、参考答案。
4. 上报失败不阻塞主流程
   - Given 日志上报通道不可用；When 用户继续操作；Then 降级为本地缓冲+静默丢弃，主流程异常不被吞掉。

## 失败判定（通用）

任何场景中，若观察到以下任一情况即判定**不通过**：出现 mock 成功响应充当交付；把未完成评测显示为 0 分；静默丢弃被拒行；把前端隐藏按钮当作安全边界；日志中出现 token/参考答案/PII。
