# B1 信任边界与数据边界

## 信任边界

| 层 | 内容 |
|---|---|
| 谁能调用我 | 我无服务端端点（`routes: []`）；我的构建产物由 MAIN host 提供给浏览器。 |
| 我信任什么 | 契约锁定的接口语义（`../../../MAIN/contracts/**`）；后端已完成独立鉴权与鉴权结果。 |
| 我不信任什么 | **一切外部输入**：题干富文本（可含脚本/内联事件）、名单文件内容、URL 参数、后端返回的字符串字段、`X-Request-ID` 之外的任意头。 |

因此：

- 富文本必须白名单渲染，**不执行**题干中的脚本/内联事件（RQ-B-1-40-3）。
- 从后端拿到的任何字符串字段都按"可能是攻击载荷"处理，展示前转义/白名单。
- 前端隐藏按钮/路由守卫**不构成信任边界**；所有授权判定在 B4/B2/B3 服务端（RQ-B-1-20）。

## 数据边界

- **我只读写**：浏览器本地存储里的**未提交草稿**与 **UI 偏好**（主题、语言等）。
- **我禁止触碰**：任何 `b2`/`b3`/`b4` schema；任何后端数据库；任何服务端文件系统。
- **我禁止存储**：访问令牌、刷新令牌、cookie 值、参考答案、隐藏测试、学号之外的学生 PII、他人成绩。
- 详见 `../database/schema.md`。

## 安全边界

| 项 | 规则 |
|---|---|
| 密钥/凭据 | B1 不接触任何长期密钥；访问令牌由 HttpOnly cookie 携带（刷新凭据仅 HttpOnly + Secure + SameSite cookie），**绝不**写 localStorage；B1 不解析、不缓存 JWT 明文。 |
| 日志脱敏 | 前端日志**不得**包含 token、参考答案、隐藏用例、学号明文之外的 PII、源码内容（RQ-B-1-99）。 |
| 导出 | B1 只触发下载与渲染文件名；公式注入转义由 B2 导出端保证，B1 不得二次拼接导出内容（RQ-B-1-60）。 |
| 图片 | 只经受控 URL 加载；未授权 403；禁止把图片响应伪装为可执行文档。 |

## 与"我能碰什么"的落地清单

- 能碰：`../../src/**`、`../../docs/**`、`../../module.yaml`、`../../contracts.lock`、`../../package.json`、`../../tsconfig.json`、`../../vite.config.ts`、`../../.env.example`、`../../.gitignore`。
- 不能碰：`../../../MAIN/**`（尤其 `../../../MAIN/contracts/**`）、其他模块目录、任何后端数据库/中间件。
