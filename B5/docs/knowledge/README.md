# 知识笔记索引

## 收录标准

一条笔记要被收录，必须同时满足：

1. **同一个根因至少出现过两次**，或有**稳定复现**的完整证据（命令 + 输出）；
2. 结论对**下一个接手的人**有直接行动价值（"下次怎么做"而不是"当时发生了什么"）；
3. 不重复已有文档：纯粹的接口事实归契约，流程归 `../collaboration/`，阶段过程归 `../phases/`。

不收录：一次性笔误、纯环境噪声、没有结论的排查过程。

## 命名与模板

文件名：`YYYY-MM-DD-<短问题名>.md`（例如 `2026-09-18-lock-tool-skips-b5.md`）。

```md
# <一句话现象>

- **现象**：
- **重复触发条件**：（什么输入/环境下必然出现）
- **根因**：
- **最终修复**：（改了什么，或为什么决定不改）
- **预防措施**：（哪个门禁/断言现在会拦住它）
- **关联证据**：（命令与输出、阶段文档、ADR/CHG 编号）
```
