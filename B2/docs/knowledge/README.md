# B2 知识笔记索引

只收录**同一根因至少出现两次、且有稳定修复**的问题。一次性故障或未验证的猜测不收录（记在 `../phases/active/` 或 `../runbooks/troubleshooting.md`）。

## 收录标准

1. 同一根因至少出现两次（不同时间/不同人/不同提交）。
2. 已有稳定修复（可复现地解决）。
3. 根因与修复能写清，非"重试就好了"。

## 命名规则

`YYYY-MM-DD-<short-problem>.md`，如 `2026-09-15-uv-cache-sandbox-write-fail.md`。

## 模板

```md
# 现象
（一句话：什么报错 / 什么症状）

# 重复触发条件
（在什么环境/操作下可复现）

# 根因
（真正的原因，不是表象）

# 最终修复
（可执行的修复步骤）

# 预防措施
（如何避免再次发生）

# 关联证据
（链接到 phase 记录 / 测试 / issue）
```
