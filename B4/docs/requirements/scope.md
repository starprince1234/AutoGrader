# B4 范围与非目标

## 范围

B4 交付平台底座五类能力（均已实现，证据见 `../phases/active/phase-01-platform-implementation.md`）：

1. **身份与凭据**（`已完成`）：用户、凭据（Argon2id）、会话；Ed25519 短期 JWT + JWKS；刷新凭据仅
   `HttpOnly`/`Secure`/`SameSite` cookie，轮换并检测重用。
2. **角色与作用域授权**（`已完成`）：学生 / 教师 / 助教 / 管理员；授权判定在服务端（前端隐藏不构成
   安全）；每一次拒绝入审计。
3. **课程主数据**（`已完成`）：课程、课序、选课；名单导入（解析→映射→校验→预览→确认→原子写入）。
4. **基础设施运维**（`已完成`）：PostgreSQL 实例 / 最小权限角色 / schema / 健康 / 备份恢复演练；
   NATS JetStream 的 stream / durable consumer / DLQ / 重放 / outbox。
5. **运行期模块注册表**（`已完成`）：发现已装载模块、暴露 `descriptor`、聚合健康、路由/事件/能力/
   迁移 head 查询；漂移在启动时明确失败（设计期契约归 MAIN，见 ADR-0003）。

## 非目标（越界即缺陷）

- 不拥有 B2/B3 物理表；不代管其迁移与表结构（也**无权限**访问——已实测被数据库拒绝）。
- 不是 MAIN 契约作者；不新增/改名/删除契约路径、operationId、subject、字段。复核中发现的契约缺口
  记录在 `../api/contract.md`，走变更规程而非私改。
- 不执行学生代码、不评分、不拥有题目 / 评测 / 成绩。
- 不用超级用户跑应用（启动即拒绝）；不做跨 schema 外键 / 视图 / 共享 ORM。

## 角色与用例

- **管理员**：用户增删改、角色分配、审计查询（全量）、注册表全量、备份与健康运维。
- **教师 / 助教**：课程 / 课序 / 选课维护、名单导入（限授权课程作用域）、本课程审计查询。
- **学生**：登录、读取本人信息与本人选课（无管理写权限）。
- **运维 / MAIN**：注册表与健康聚合只读（管理员范围）；公开端点仅存活。

## 上游输入 / 下游输出

- **上游**：B1 提交登录与名单导入请求；MAIN 提供契约与 host 装载上下文（settings、health 钩子）。
- **下游**：给 B1/B2/B3 提供身份令牌与 JWKS（本地验签，不回调）；发布
  `autograder.v1.roster.import.completed`（不含 PII）给订阅方。
