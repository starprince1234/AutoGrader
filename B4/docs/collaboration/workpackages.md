## 并行前提（必须先冻结，谁冻结）

1. **`b4` schema 初始迁移与平台表**（A3）——B1/B2/B3/B4 都依赖，先冻结。
2. **JWT 签发/校验的内部接口签名**（B1 产出，其他模块按它做本地验签）。
3. **角色与作用域取值集合**（学生/教师/助教/管理员 + 课程作用域表达）——冻结后其他模块才能写授权逻辑。
4. **表结构规范**（A2 产出，A3/B* 必须遵守）。
5. **名单导入状态机语义**（B4 内部，但被 B1 依赖，需先冻结）。

- 可并行：A 与 C 几乎无耦合；B 依赖 A 的迁移骨架与角色供给。
- 共享文件冲突预防：`plugin.py` descriptor、`alembic/`、角色常量模块、错误码目录为共享文件，改动需在认领表注明。
