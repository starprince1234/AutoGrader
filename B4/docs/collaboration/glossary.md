# B4 术语表

本模块专有/高频术语；跨模块全局标识与作用域见 `../../MAIN/docs/api/identifiers.md`。

| 术语 | 含义 |
|---|---|
| 平台底座 | B4 的定位：身份/课程/审计主数据 + PostgreSQL/NATS 运维 + 运行期注册表 |
| 身份权威 | B4 是唯一签发令牌、定义角色的一方；其他模块本地验签不回调 |
| JWKS | JSON Web Key Set，暴露 Ed25519 公钥供本地验签，`kid` 标识轮换 |
| 短期 JWT | Ed25519 签名、短有效期的访问令牌，含 `iss`/`aud`/`role`/课程作用域 |
| 刷新凭据 | 长生命周期凭据，仅存 `HttpOnly`+`Secure`+`SameSite` cookie，用于换新短期 JWT |
| 课程作用域 | 授权判定第三层：请求 `course_id`/`section_id` 须在用户授权集合内 |
| 名单导入管道 | 解析→映射→校验→人工确认→原子写入的固定流程，不确定即报错 |
| 原子写入 | 确认后一次事务写入，失败整体回滚；确认前零写入 |
| outbox / inbox | 事件先落 outbox 再投递；消费方按 `event_id` 做 inbox 去重 |
| DLQ | 死信队列，达最大投递次数的消息，可查可重放 |
| 运行期注册表 | B4 暴露已装载模块 descriptor/健康/能力的查询端点 |
| 设计期/运行期切分 | `RQ-B-4-40` 的切分：设计期契约归 MAIN，运行期注册表归 B4 |
| 最小权限角色 | 每模块一个 login role，仅授本 schema，禁止超级用户跑应用 |
| 软删除 | `deleted_at` 标记删除，保留审计引用，查询须说明是否排除已删 |
