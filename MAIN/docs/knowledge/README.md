# 知识笔记

知识笔记保存**可复用的工程结论**，不是日志仓库。

## 收录标准（必须同时满足）

1. **同一根因至少出现两次**（或该根因的**类别**已被证明会在本项目重复发生并已有自动化预防）。
2. **根因已经过证据验证**——不是猜测，不是表面错误。
3. **已有稳定的修复与预防措施**（回归测试、静态规则、检查脚本、设计约束或运行手册条目）。

## 不收录的内容

| 不收录 | 原因 |
|---|---|
| 一次性拼写错误 | 无复用价值 |
| 尚未确认根因的猜测 | 会误导后来者 |
| 单纯的命令输出或报错粘贴 | 不是结论 |
| 能直接从官方文档查到的常识 | 属于文档检索，不属于项目知识 |
| 含密钥、个人信息或生产数据的现场信息 | 安全与隐私 |
| 纯粹的阶段流水 | 属于 `phases/` |

## 命名

`YYYY-MM-DD-short-problem.md`，日期为该问题的**稳定结论**得出之日。

## 模板

```md
# 问题名称

## 现象
用户可观察行为、错误信息和受影响范围。

## 重复触发条件
问题至少两次出现的环境、输入或操作条件。

## 根因
经过证据验证的技术原因；不要只写表面错误。

## 最终修复
采用的方案、关键实现和为什么能够消除根因。

## 预防措施
回归测试、静态规则、监控、运行手册或设计约束——必须指明**现在**由什么阻止它复发。

## 关联证据
代码、测试、issue、ADR、日志片段或版本链接。
```
