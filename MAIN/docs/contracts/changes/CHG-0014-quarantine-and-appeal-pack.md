# CHG-0014 隔离区复核台与证据包：两处"写进去就读不出来"

- **级别**：P1 增补（三个端点 + 两个 schema）
- **状态**：已生效（2026-09-18 判定）
- **契约版本**：0.8.0 → **0.9.0**
- **依据**：创新清单簇 B 第 5、6 项；`ADR-0005`（证据可复核）

## 1. 问题

两处都是**数据一直在写、但没有任何读出口**——与 `CHG-0013` 是同一类：能力在，出口不在。

### 1.1 隔离区：匹配失败的邮件对教师"静默消失"

`b2.intake_quarantines` 自邮件接收路径建成起就在写：**无法解析出作业标识**或**被拒**的来件会被
记在那里，而不是被丢掉。但**没有任何读取路径**。

集成审计的措辞很准确：从教师的角度看，未匹配的邮件**无声无息地不见了**。学生说"我交了"，
教师查不到，系统里也没有地方能查到——这不是"少一个页面"，是**交付链断了一环**。

### 1.2 申诉证据：报告只能看，不能带走

成绩争议要用证据回答，而证据必须**可移动**：一个没有登录本部署的复核者应当能**仅凭文件**
判断这次判分是否成立。现有报告端点要求调用方在线，且不含"重现方式"。

## 2. 变更内容

### 2.1 `GET /api/v1/intake/quarantines`

分页列出隔离记录，可按 `reason_code` 与 `resolved` 过滤（教师想要的默认视图是**未处理的**）。
`IntakeQuarantineView` 只含识别性元数据与**已脱敏**的原因说明：目的是让教师能**在自己的邮箱里
重新找到那封信**，而不是把平台变成第二个邮件仓库——因此它不含附件内容、学生源码或提交的任何部分。

### 2.2 `POST /api/v1/intake/quarantines/{id}/resolve`

教师认出这封信是谁的，手动归属。两条性质**不可协商**，都写进契约描述：

1. **手动路径重跑与自动路径相同的校验。** 归属只提供自动匹配未能得出的**身份**，不跳过信封、
   摘要与作用域检查。一条绕过校验的手动通道会把"匹配器不确定"变成"什么都行"——那与隔离区的
   存在目的正好相反。
2. **归属不顺手触发重评。** 它记录归属，把评测留给正常的提交路径，于是审计追踪呈现的是
   "人的决定 → 常规机器流程"。

`student_id` 用的是平台用户 id —— 与 `CHG-0007` 给名单加的**同一个键**，于是"这是谁"的两侧
终于用同一个标识符。

### 2.3 `GET /api/v1/evaluation-runs/{id}/appeal-pack`

自包含的 `AppealPack`：报告 + 五元绑定摘要 + runner 策略摘要 + **可读的重现说明**，并由
`result_digest` 钉住（读者可自行重算以发现篡改）。

两处**强制脱敏**，也正是它必须是专门文档、而不是"报告端点加个下载头"的原因：

- **宿主绝对路径被移除** —— 证据包会离开这台机器，而绝对路径描述了内部布局；
- **导出永不扩大可见范围** —— 证据包携带的是调用方**本来就有权看到**的内容，产出它不能变成
  获取隐藏用例或期望输出的途径。

`redactions` 字段**列出**被移除的内容而不是暗示：一个静默省略了东西的证据包，与一个本来就没东西
可省的证据包无法区分，而读者被要求信任这份文件。

## 3. 路由前缀

两个 intake 端点落在**新前缀** `/api/v1/intake` 下，因此 `B2/module.yaml` 的 `routes` 与
B2 descriptor 的 `routes` 都已补入该前缀（MAIN 侧已在本次变更中同步，见 §4）。
放在独立前缀而不是塞进 `/api/v1/submissions`，是因为它不是提交端点——它服务的是
**从未成为提交的那些邮件**。`appeal-pack` 落在既有的 `/api/v1/evaluation-runs` 前缀下，无需改动。

## 4. 是否破坏兼容

**否。** 三个端点均为新增。MINOR 升到 0.9.0。

## 5. 受影响模块与需要做的改动

| 模块 | 改动 |
|---|---|
| **B2** | 实现三个端点；隔离区读取路径；手动归属重跑校验；证据包组装与两处脱敏 |
| **B1** | 教师可见的隔离区复核界面（列出、按原因筛选、归属到学生）；成绩页可下载证据包 |
| **MAIN** | 本变更；五份锁、五份 `module.yaml`、四个描述符同步 0.9.0；`B2/module.yaml` 与 descriptor 补 `/api/v1/intake` |

## 6. 验证

```powershell
cd MAIN
.\.venv\Scripts\python.exe -m autograder_host.checks
```

本变更特有的验证（**实现落地后才可执行，未完成前不得声称已通过**）：

1. **手动归属真的重跑校验**：构造一封信封摘要不匹配的隔离邮件，手动归属后**仍然被拒**——
   若它能因"人工"而通过，本变更就引入了一个绕过校验的后门；
2. **证据包不含宿主绝对路径**：对打包结果做扫描，断言不含工作区路径前缀；同时 `redactions` 非空；
3. **导出不扩大可见范围**：以学生身份请求证据包，断言隐藏用例与期望输出**不在其中**，
   与报告端点的 `student` 视图一致；
4. **未匹配的邮件可被找到**：写一条隔离记录后能在列表里查到，且 `resolved=false` 过滤有效。

## 7. 回滚方式

删除三个端点与两个 schema，重新运行 `scripts/relock_contracts.sh` 等价命令（`relock_contracts.py`）。
**同时**要把 `B2/module.yaml` 与 descriptor 的 `/api/v1/intake` 前缀一并移除，否则路由门禁会报
"声明的前缀不覆盖任何契约路径"。回滚会使未匹配邮件重新变为不可见，因此必须在 B2 的追踪表与
审计记录里写明这一点，而不是只删端点。
