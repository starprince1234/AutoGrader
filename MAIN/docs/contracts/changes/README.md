# 契约变更记录（CHG）

本目录存放**每一次契约变更的提案与结果**。流程见 [`../../contracts/change-protocol.md`](../../contracts/change-protocol.md)；变更历史摘要见 [`../../../contracts/CHANGELOG.md`](../../../contracts/CHANGELOG.md)。

**分工**：

| 文件 | 记录什么 |
|---|---|
| `MAIN/contracts/CHANGELOG.md` | **契约内容**按版本的累积历史（追加式） |
| 本目录 `CHG-NNNN-*.md` | **单次变更**的动机、影响分析、受影响模块、迁移与回滚 |
