# CHG-0010 新增 B5：平台一致性审计模块

- **级别**：P1 增补（新增模块与一个端点）
- **状态**：已生效（2026-09-18 判定）
- **契约版本**：0.4.0 → **0.5.0**
- **依据**：[ADR-0013](../../adr/ADR-0013-open-module-count.md)（模块数开放）、PRD §8.6

## 1. 问题：头条目标从未被验证过

PRD §8.6 把项目的头条目标写成一条可测判据：

> **解耦**：新增一个遵守规范的模块，**无需修改 MAIN 代码**即可装载。

在 B5 之前，这句话**没有任何证据**。四个模块都是与 MAIN 同步长出来的——它们的清单、契约摘要、
文档结构是在约定尚未冻结时反复协商的结果。要证明"规范真的够用"，只有一个办法：

**在规范冻结之后，照着规范写一个新模块，看它能不能不改 MAIN 就装进来。**

集成审计还发现三处硬编码把这条路封死（`^B[1-4]$` 出现三次、MAIN 把业务模块作为核心依赖、
治理门禁里模块列表是字面量），ADR-0013 已逐条处置。B5 是该 ADR 的**验收物**。

## 2. 变更内容

### 2.1 新增 `openapi/b5.yaml`

一个端点：

| 端点 | 用途 |
|---|---|
| `GET /api/v1/platform/conformance` | 报告**运行中的**组合与契约之间的差异 |

三视图比对：契约声明的路径 / host 自己服务的平台级路由（`/health/*`，**有意在契约之外**）/
各模块描述符声明的路由。每条差异标明**哪一侧缺失**，而不是给一个计数——计数无法据以行动。

`ConformanceReport` 的 `consistent` 仅在三者一致时为真。返回**报告**而非报错：调用者来读的就是
不一致本身；真正会失败的是 MAIN 门禁里的机器可检形式。

授权：任何已认证主体可读。它只暴露端点**名称**与计数，不含载荷、源码、凭据或题目内容。

### 2.2 为什么这是"增补"而不是"破坏"

新增一个契约文件与一个端点，不改变任何既有路径、字段或状态码。既有四个模块不需要任何改动。
按 MINOR 升到 0.5.0。

> 注意一个**有意的后果**：`declared_contract_version()` 会断言**所有**契约文件的 `info.version`
> 一致，因此新增 b5.yaml 会自动要求五个文件、四份锁、五个 `module.yaml` 与三个描述符全部同步到
> 0.5.0。这不是副作用，而是本变更想要的效果——契约是一个整体，不存在"只有新模块用的版本"。

## 3. 受影响模块与需要做的改动

| 模块 | 改动 |
|---|---|
| **MAIN** | 本变更；四份锁与 B1–B4 的 `module.yaml` 同步 0.5.0；B2/B3/B4 描述符同步 0.5.0 |
| **B5**（新） | 按 `module.yaml` + `contracts.lock` + 文档治理规范完整实现；提供 capability，并**声明对既有能力的依赖**以验证 capability DAG 的真实排序 |
| **B1–B4** | 仅版本号同步，无代码改动 |

## 4. 是否破坏兼容

**否。** 纯增补。

## 5. 验证

```powershell
cd MAIN
.\.venv\Scripts\python.exe -m autograder_host.checks
```

本变更特有的验证（**必须由 B5 的落地来证明，未完成前不得声称已通过**）：

1. `discovered_modules()` 返回五个模块——即治理门禁**自动**纳入了新模块（这正是 ADR-0013 修掉的
   "装载了却逃过治理"）；
2. `module_schema_owners()` **不**包含 B5（它没有数据库 schema），证明发现式判定按清单字段而非按名字猜；
3. host 的 `_load_modules()` 装载五个模块，且顺序仍满足 capability DAG；
4. 一个**负例**：故意破坏 B5 的清单/能力声明时，装载与门禁**各自**报错（而不是静默通过）。

第 4 条尤其重要：一个只会"通过"的一致性套件证明不了任何事。

## 6. 回滚方式

删除 `b5.yaml` 与 `B5/`，重新运行 `scripts/relock_contracts.py`，五处版本同步回 0.4.0。
回滚会让 PRD §8.6 重新变回一句无法验证的话，因此回滚必须同时修改该判据——不能只删代码。
