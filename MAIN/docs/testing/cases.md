# 跨模块测试用例目录

本文件是 **MAIN 层**的用例目录：集成、端到端、安全、可重放、资源、文档门禁用例。各模块自己的单元/契约用例在其 `docs/testing/cases.md`。

**"存在"列的含义**：`无` = 用例尚未实现；`部分` = 有相关代码但未覆盖本用例要点；`有` = 用例存在且通过（必须能指向证据）。**当前全部为 `无`**——项目处于初始化骨架阶段。不得在未实现时填写其他值。
